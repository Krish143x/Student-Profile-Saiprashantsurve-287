# Sai Surve — Student Portfolio

A responsive personal portfolio built with HTML and CSS. It introduces Sai, highlights education, skills, projects, hobbies, and achievements, and provides contact information.

## Features

- Responsive layout for desktop and mobile
- Light and dark themes with a CSS-only toggle
- Sections for about, education, skills, projects, hobbies, achievements, and contact
- No JavaScript or build tools required

## Files

```text
.
├── index.html
├── sai-surve-portrait.jpg
└── README.md
```

The portrait is stored beside `index.html` and referenced as `sai-surve-portrait.jpg`.

## Run locally

Open `index.html` in a web browser. No installation or build step is needed.

## Publish with GitHub Pages

1. Upload `index.html` and `sai-surve-portrait.jpg` to the root of the repository.
2. In the repository settings, open **Pages**.
3. Choose the `main` branch and the root (`/`) folder as the publishing source.
4. Save, then open the URL provided by GitHub Pages.

Keep the image filename and its path in `index.html` in sync. Paths and filenames are case-sensitive on GitHub Pages.
